# 🛕 Famous Temples of Bharat

## Project Overview

Famous Temples of Bharat is a web application developed to help users explore famous temples across India. The application provides detailed information about temples, including their history, darshan timings, poojas, donations, festivals, and location-based search.

---

## Features

- User Registration
- User Login
- Search temples by name
- Search temples by location
- Temple history
- Darshan timings
- Pooja details
- Donation information
- Festival information
- Temple contact details
- Responsive user interface
